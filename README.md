# 鹈鹕骑自行车 · Pelican Pedal

海岸公路上的 3D 骑行：戴头盔墨镜、系红布巾的鹈鹕骑车抓鱼。

直接打开 https://.github.io/pelican-pedal/ 即可游玩（单文件，无需任何外部依赖）。

## 玩法

| 按键 | 作用 |
| --- | --- |
| W / ↑ | 加速 |
| S / ↓ | 刹车 |
| A / D 或 ← / → | 变道（鱼会落进某个车道，对准了就能抓） |
| 空格 | 跳跃（空中也能抓鱼） |
| T | 展翅抬前轮 |
| 1–5 / C | 切换镜头（追车 / 电影运镜 / 鱼眼车载 / 鹈鹕视角 / 航拍自由） |
| Tab | 成就 |
| P | 摄影模式 |
| M | 静音 · Q | 画质 |

停止操作 5 秒后，鹈鹕会自动开车去追鱼。

## 技术要点

- 纯 WebGL2 + three.js r169，单文件内联，无外部请求
- Gerstner 波方程海面（顶点位移 + 解析法线）、岸线碎浪泡沫带
- 红围巾为 Verlet 布料模拟（重力 + 阵风 + 速度阻力 + 球体碰撞）
- 鹈鹕双腿两骨 IK 蹬踏，翅膀展翅抬前轮、喉囊弹簧摆动、眨眼
- 黄昏 → 星空月夜的连续昼夜循环，天空/水面/雾/灯光全部随时间重着色
- Web Audio 实时合成音乐：BPM 跟随踏频，鼓点/贝斯/琶音/铺底 + 浪声/风声/夜虫
- 自定义后期：Bloom、ACES、暗角、色差、颗粒、速度径向模糊
- 5 种镜头（电影运镜会自动切换 4 个分镜）、14 个成就（本地存档）、触屏按钮、按帧率自适应画质
